# tasks-013: 로그인

## 목표

로그인을 "꼭 필요할 때만" 자연스럽게 하게 한다. 지금 나 탭은 로그인 안 했으면 탭 바 없는 임시 로그인 화면(`/login`)으로 넘어가는데, 이걸 나 탭 안의 화면으로 바꾼다. 로그인하면 이 기기에서 참여한 공연이 계정으로 합쳐져 다른 기기에서도 보인다.

## 범위

- 포함: 나 탭 비로그인 화면(M-1), 나 탭 로그인 화면, 로그인이 필요한 순간의 안내, 로그인 뒤 원래 화면으로 돌아오기, 기기 참여 → 계정 합치기, 로그인한 회원의 참여를 서버에 저장, 온보딩 정리, 이용약관·개인정보 처리방침
- 제외: 예매 인증(다음 작업), 커뮤니티 글쓰기(커뮤니티 작업), 카카오 외 로그인, 회원 탈퇴 외 계정 관리, 알림
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "나 탭" 두 줄 — M-1(비로그인), M-3(로그인 시트), M-4~M-6(로그인·닉네임·탈퇴). 화면 제목은 "프로필"

## 체크리스트

### 0. 결정

정한 것

- [x] 나 탭 비로그인(M-1): 탭 바 유지. "로그인하지 않았어요" 카드 + 카카오로 시작하기 + 로그인하면 좋은 점(다른 기기에서도 내 공연 · 커뮤니티 글쓰기 · 예매 인증하고 건의), 그 아래 "이 기기"(참여한 공연 N개), "서비스"(공연 추가 요청 · 이용약관 · 개인정보 처리방침)
- [x] 보는 건 로그인 없이(PRD 그대로). 로그인은 커뮤니티 글쓰기, 예매 인증, 다른 기기에서도 보기에만

정한 것(추천대로, 2026-10-21)

- [x] `/login` 화면: 추천은 없애고 나 탭(`/me`)으로 보냄. 카카오 로그인 실패도 나 탭에서 "로그인하지 못했어요" 안내
- [x] 로그인이 필요한 순간: 추천은 그 자리에서 아래 시트(M-3) "○○하려면 로그인이 필요해요" + 카카오로 시작하기 + 다음에 할게요. 화면을 떠나지 않음
- [x] 로그인 뒤 돌아오기: 추천은 로그인을 누른 화면으로 돌아옴(나 탭이면 나 탭, 공연 홈이면 그 공연 홈)
- [x] 닉네임: 중복 불가(지금처럼). 처음 로그인하면 랜덤 닉네임으로 채워 두고 나 탭에서 바꿀 수 있게(2026-10-21)
- [x] 랜덤 닉네임 모양: 추천은 "꾸밈말 + 공연 낱말 + 숫자 4자리"(예: 신나는떼창0428, 들뜬응원봉1173). 20자 안, 겹치면 숫자만 다시 뽑음
- [x] 온보딩(닉네임·성별 화면): 추천은 없앰. 성별은 안 받고, 로그인하자마자 한 화면 더 거치지 않게
- [x] 기기 참여 합치기: 추천은 아래 규칙. 여러 기기(폰·PC)에서 로그인해도 충돌 없게
  - 합치기는 로그인하는 그 순간 한 번만. 그 기기의 참여 목록을 계정에 더하기만 하고 빼지 않음(겹치면 하나)
  - 로그인한 뒤로는 서버 목록이 기준. 화면을 열 때마다 서버 목록을 받아 기기 저장소를 덮어씀. 열 때마다 합치면 다른 기기에서 취소한 공연이 되살아나서 안 됨
  - 로그인한 동안 참여·참여 취소는 서버에 저장하고 기기 저장소도 같이 맞춤
  - 로그아웃하면 그때 목록을 기기에 그대로 남김. 그 뒤 다른 기기에서 취소한 공연이, 이 기기에서 다시 로그인할 때 합치기로 되살아날 수 있음(드물고 다시 취소하면 됨, 받아들임)
  - 예: 폰 {A,B} 로그인 → 계정 {A,B} / PC {C} 로그인 → 계정·PC {A,B,C} / PC에서 B 취소 → 계정 {A,C}, 폰을 다시 열면 {A,C}
- [x] 볼 것 ★: 추천은 이번엔 기기에만(합치지 않음). 타임테이블이 바뀌면 순서 ID가 달라질 수 있어서 나중에. 나 탭에는 안 보여 줌(모아 보는 화면이 없어서)
- [x] 로그인한 나 탭: 추천은 M-1과 같은 틀. 카드에 닉네임 · "카카오로 로그인됨" · 수정, 그 아래 "내 공연"(참여한 공연 N개), "서비스", 맨 아래 로그아웃 · 탈퇴. 시안 필요
- [x] 회원 탈퇴: 추천은 이번에 만듦(카카오 로그인 심사·개인정보 처리방침에 필요). 탈퇴하면 계정과 참여 기록을 지움
- [x] 이용약관·개인정보 처리방침: 추천은 앱 안 페이지(`/terms`, `/privacy`) 두 개. 모으는 정보: 카카오 회원번호·닉네임, 참여한 공연, 현장 QR 기기 ID, 건의 내용·사진
- [x] 로그인 세션 길이: 지금 30일. 추천은 그대로

### 1. 데이터

- [x] `participations`: 회원, 공연, 참여한 시각(회원·공연 하나씩만)
- [x] 회원 성별 칸: 안 쓰면 비워 둠(지우지는 않음)

### 2. 백엔드

- [x] 참여 API: `/api/me/participations` 목록 · 더하기(여러 개 한 번에, 합치기용) · 빼기
- [x] 처음 로그인하면 랜덤 닉네임(겹치지 않게)으로 회원 만들기, 온보딩 조건 없애기
- [x] 회원 탈퇴 API: 계정·참여 지우기, 세션 끝내기
- [x] 테스트: 랜덤 닉네임이 겹치지 않음, 닉네임 바꾸기(중복 거절), 합치기(겹치는 공연 하나만, 계정에만 있는 공연은 그대로), 참여·취소, 다른 회원 참여는 안 보임, 탈퇴하면 참여도 사라짐, 비로그인 401

### 3. 프론트

- [x] 프로필 탭(제목 "프로필") 비로그인(M-1), 로그인(M-4), 닉네임 바꾸기(M-5), 탈퇴(M-6)
- [x] `/login` 없애기(나 탭으로 보내기), 로그인 실패 안내
- [ ] 로그인 시트(M-3): 지금은 로그인이 필요한 화면이 프로필뿐이라 커뮤니티 글쓰기와 함께 만듦
- [x] 로그인 뒤 원래 화면으로 돌아오기
- [x] 로그인하면 기기 참여를 계정에 합치고, 홈·참여 버튼이 계정 기준으로
- [x] 온보딩 화면 없애기, 나 탭에서 닉네임 바꾸기

### 4. 완료 기준

- [x] 이 기기에서 공연 2개에 참여하고 로그인하면, 다른 기기에서 로그인해도 그 2개가 홈에 보인다
- [x] 로그인하면 로그인을 누른 화면으로 돌아온다
- [x] 탈퇴하면 계정과 참여 기록이 지워진다
