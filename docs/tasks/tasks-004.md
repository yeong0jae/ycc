# tasks-004: 로그인 · 시작 설정 · 하단바

## 목표

카카오로 로그인하고 닉네임·성별을 정한 뒤, 하단바(콘서트 / 내 동행 / 내 정보)로 화면을 오갈 수 있게 한다. 이후 예매 인증·동행 기능의 바탕이 된다.

## 범위

- 포함: 카카오 로그인·로그아웃, 시작 설정(닉네임·성별), 내 정보 화면 뼈대, 하단바, 로그인 필요한 화면 막기
- 제외: 예매 인증, 동행 올리기·요청, 내 동행 내용(빈 화면만), 프로필 사진, 회원 탈퇴

## 체크리스트

### 0. 결정

- [x] 로그인 수단: 카카오 로그인 하나
- [x] 로그인 처리: 백엔드(Spring Security OAuth2 Client)가 카카오 로그인을 처리하고 세션 쿠키를 발급
- [x] 세션 저장: Spring Session JDBC (MySQL). 서버를 다시 띄워도 로그인 유지
- [x] 카카오에서 받는 정보: 회원번호만. 닉네임·성별은 시작 설정에서 직접 입력
- [x] 성별: 여성 / 남성 / 밝히지 않음. 다른 사람에게 보이지 않고 "동성만" 동행에서만 사용
- [x] 하단바: iOS Liquid Glass 캡슐형, 탭 3개 (콘서트 / 내 동행 / 내 정보)
- [x] 하단바 표시: 목록·지도·내 동행·내 정보에서만. 상세 등 작업 화면에서는 숨김
- [x] 로그인 없이: 콘서트 목록·지도·상세는 볼 수 있음. 내 동행·내 정보는 로그인으로 보냄
- [x] 카카오 콘솔: 카카오 로그인 사용 설정, Redirect URI `http://localhost:8080/login/oauth2/code/kakao` 등록
- [x] 루트 `.env`에 `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET` 추가

### 1. 데이터

- [x] `users` 테이블: 카카오 회원번호(고유), 닉네임, 성별, 가입일
- [x] Spring Session 테이블

### 2. 백엔드

- [x] 카카오 로그인 → 처음이면 사용자 생성 → 시작 설정 전이면 시작 설정으로, 아니면 콘서트 목록으로
- [x] `GET /api/me`: 내 정보 (로그인 안 했으면 401)
- [x] `PUT /api/me`: 닉네임·성별 저장 (닉네임 2~12자, 중복 불가)
- [x] `POST /api/logout`
- [x] 테스트: 로그인 사용자 생성, 내 정보 조회·수정, 미로그인 401, 닉네임 검증

### 3. 프론트

- [x] 하단바 컴포넌트, 목록·지도·내 동행·내 정보에 배치
- [x] 로그인 화면 (카카오로 시작하기)
- [x] 시작 설정 화면 (닉네임, 성별)
- [x] 내 정보 화면: 닉네임, 수정, 로그아웃
- [x] 내 동행 화면: 빈 상태 ("아직 동행이 없어요")
- [x] 로그인 안 한 상태로 내 동행·내 정보 접근 시 로그인 화면으로

### 4. 완료 기준

- [x] 카카오로 로그인 → 시작 설정 → 목록까지 이어진다
- [x] 서버를 다시 띄워도 로그인이 유지된다
- [x] 로그아웃하면 내 정보에 들어갈 수 없다
- [x] 로그인 없이도 콘서트 목록·지도·상세를 볼 수 있다
