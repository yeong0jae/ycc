# tasks-001: 콘서트 모아보기

## 목표

국내 콘서트를 한곳에서 날짜순으로 볼 수 있게 한다. 이후 동행 모집으로 사람을 데려오는 입구 역할.

## 범위

- 포함: 콘서트 목록, 상세 정보, 예매·공식 링크
- 제외: 동행 모집, 로그인, 검색·필터, 자동 수집(크롤링), 일본 공연

## 체크리스트

### 0. 결정

- [x] 플랫폼: 웹
- [x] 백엔드: Kotlin, Spring Boot, MySQL
- [x] 프론트엔드: Next.js (TypeScript). 백엔드는 API만 제공
- [x] 저장소 구조: 한 저장소에 `backend/`(Spring Boot), `frontend/`(Next.js)
- [x] 데이터 입력 방식: 더미 데이터를 SQL 파일로 넣음 (실제 데이터·크롤링은 나중에)

### 1. 데이터

- [x] 콘서트 필드 정의: 이름, 시작·종료일, 장소, 포스터 이미지, 출연(라인업), 예매 링크, 공식 링크
- [x] 더미 데이터 SQL 작성 (종료된 콘서트 포함 10개 내외)

### 2. 화면

- [x] 목록: 다가오는 순 정렬, 포스터·이름·날짜·장소 카드
- [x] 상세: 전체 정보, 예매·공식 링크
- [x] 종료된 콘서트는 목록에서 숨김

### 3. 완료 기준

- [x] 모바일 화면에서 목록 → 상세 → 예매 링크까지 이동된다
- [x] `docker compose up`으로 로컬에서 MySQL·백엔드·프론트가 함께 뜬다
