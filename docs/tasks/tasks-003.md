# tasks-003: 콘서트 지도로 보기

## 목표

지금 목록은 그대로 두고, 같은 콘서트를 지도 위에서도 볼 수 있게 한다.

## 범위

- 포함: 공연장 좌표 수집, 지도 화면, 목록 ↔ 지도 전환
- 제외: 내 위치 기준 정렬·거리 표시, 지도에서 날짜 필터, 길찾기

## 체크리스트

### 0. 결정

- [x] 목록은 유지하고 지도 화면을 추가 (목록 ↔ 지도 전환)
- [x] 좌표 출처: KOPIS 공연시설상세(`/prfplc/{mt10id}`)의 `la`·`lo`
- [x] 지도: 카카오맵 JavaScript SDK
- [x] 카카오맵 앱 키 발급, 도메인(`http://localhost:3000`) 등록
- [x] 같은 공연장 공연은 마커 하나로 묶기

### 1. 데이터

- [x] `facilities` 테이블 추가: KOPIS 시설 ID(`mt10id`, 고유), 이름, 주소, 위도, 경도
- [x] `shows`에 `facility_id` 추가
- [x] 동기화: 공연 상세의 `mt10id`로 공연장 연결, 처음 보는 공연장만 시설상세 조회
- [x] API: 공연장별로 다가오는 공연을 묶어서 주기

### 2. 화면

- [x] 목록 상단에 목록 / 지도 전환
- [x] 지도: 공연장마다 마커, 공연 수 표시
- [x] 마커를 누르면 그 공연장의 공연 목록, 공연을 누르면 상세로 이동
- [x] 첫 화면 위치: 서울 시내

### 3. 완료 기준

- [x] 목록에서 지도로 바꾸면 공연장 마커가 보인다
- [x] 마커 → 공연 → 상세로 이동된다
- [x] 목록 화면은 지금과 똑같이 동작한다
