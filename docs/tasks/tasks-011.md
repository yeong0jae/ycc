# tasks-011: 타임테이블

## 목표

공연 홈의 "타임테이블" 탭에서 관객이 날짜·무대별 순서를 본다. 앱이 그린 시간표(지금 하는 순서가 보이는 블록)와, 주최측이 인스타에 올리던 공식 이미지 둘 다 볼 수 있게 한다.

## 범위

- 포함: 주최측 페이지의 타임테이블 편집(무대·순서·공개), 공연일별 공식 이미지 올리기, 공연 홈 타임테이블 탭(시간표 · 공식 이미지 보기)
- 제외: 시간 변경 표시, 시간 변경 시 일정 변경 공지 자동 올리기, 관심 아티스트 표시·알림, 아티스트 데이터, 무대 위치 지도, 블록 끌어서 옮기기
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "타임테이블" 줄 — T-5 시간표, T-7 공식 이미지 보기, T-8 주최측 타임테이블

## 체크리스트

### 0. 결정

정한 것

- [x] 보기: 시간표와 공식 이미지 둘 다. 날짜 알약 옆 `시간표 | 공식 이미지` 토글로 오감
- [x] 시간표 디자인(D-1, 일본 페스 앱 스타일): 왼쪽 시간 축(정각 숫자, 15분 옅은 줄), 무대마다 세로 칸. 무대마다 색(파랑 · 주황 · 초록 · 분홍), 같은 무대 안에서 순서마다 연하게·진하게 번갈아. 시작 시각("14:00~")은 블록 바로 위, 블록 안에는 출연만. 지금 하는 블록은 라임 테두리와 라임 시각 태그, 지금 시각은 라임 선, 지난 블록은 흐리게
- [x] 공식 이미지(T-7): 주최측이 공연일마다 올린 이미지를 폭에 맞춰 보여 주고, 누르면 앱 안 크게 보기(확대 가능). "주최측 · 올린 날짜"
- [x] 쓰는 사람: 주최측 페이지에서만. 주최측이 아직 없는 공연은 개발자가 그 공연의 주최측 계정으로 들어가 씀. PRD의 "개발자가 개발자 페이지에서"를 이에 맞게 고침
- [x] 편집 화면(T-8): 관객 화면과 같은 블록 칸. 빈 곳을 누르면 그 시간에 추가, 블록을 누르면 수정(출연 · 무대 · 시작 · 끝, 저장 · 지우기). 끌어서 옮기기는 안 만듦. 휴대폰에서는 수정 칸이 아래에서 올라오는 시트
- [x] 자정 넘는 순서: "25:30"처럼 입력, 관객에게는 "01:30"으로 보이고 그 공연일 맨 뒤에 놓임
- [x] 시간 변경 표시·일정 변경 공지 연동: 안 만듦. 알릴 일이 있으면 주최측이 공지를 따로 올림
- [x] 공식 이미지 개수: 공연일마다 여러 장. 크게 보기에서 넘겨 봄

정한 것(추천대로, 2026-10-20)

- [x] 공개: 추천은 시간표 전체에 "관객에게 공개" 스위치 하나. 다 채운 뒤 켜면 보임. 공식 이미지는 올리면 바로 보임(이미 완성된 것이라)
- [x] 처음 보여 줄 보기: 추천은 시간표이 공개돼 있으면 "시간표", 아니고 공식 이미지만 있으면 "공식 이미지". 둘 다 없으면 탭에 "아직 타임테이블이 없어요". 관객이 토글로 고른 보기는 그 기기에서 기억
- [x] 날짜 처음 선택: 추천은 공연 기간 안이면 오늘, 아니면 첫날
- [x] 지금 위치로: 추천은 공연 당일 들어오면 지금 선이 화면 위쪽 1/3쯤 오게 스크롤
- [x] 블록을 눌렀을 때(관객): 추천은 아무것도 안 함. 블록에 필요한 정보(출연·시간·길이)가 다 보이고, 시트를 띄울 만한 추가 정보가 아직 없음. 출연 이름이 길어 잘리면 그때 시트를 검토
- [x] 무대가 많을 때: 추천은 색이 파랑 · 주황 · 초록 · 분홍 순으로 다시 돌고, 4개까지는 한 화면에 들어가고 5개부터 무대 칸을 옆으로 넘김(시간 축은 고정)
- [x] 무대 이름: 추천은 주최측이 적은 그대로(한글·영문 모두). 대문자 바꾸기 같은 건 안 함
- [x] 같은 무대 시간 겹침: 추천은 막지 않고 경고만
- [x] 한꺼번에 넣기: 추천은 이번엔 안 만듦(한 블록씩 추가)
- [x] 새로 반영: 30초마다 확인하지 않음. 탭을 열 때·새로고침할 때 최신으로 받음(타임테이블은 자주 안 바뀜)
- [x] 공연 홈 탭: 추천은 타임테이블 탭을 항상 열어 둠(비어 있으면 안내 문구). 건의·커뮤니티는 계속 "곧 열려요"

### 1. 데이터

- [x] `timetable_stages`: 공연, 이름, 순서
- [x] `timetable_slots`: 공연, 무대, 공연일, 시작·끝(공연일 0시부터 분, 24시 넘을 수 있음), 출연
- [x] `timetable_images`: 공연, 공연일, 순서, 저장 위치, 가로·세로(공지 이미지 저장소 재사용)
- [x] 공연의 시간표 공개 여부

### 2. 백엔드

- [x] 주최측 API: 무대 추가·이름 바꾸기·순서·지우기, 블록 추가·고치기·지우기, 공개 켜고 끄기, 공연일별 공식 이미지 올리기·지우기·순서. 자기 공연만(아니면 403). 공연일은 공연 기간 안, 시작 < 끝
- [x] 관객 API: `/api/shows/{id}/timetable` — 공연일 목록, 무대, (공개됐으면) 블록, 공연일별 공식 이미지. 로그인 없이
- [x] 테스트: 블록 추가·고치기·지우기, 다른 공연 403, 기간 밖 날짜·시작이 끝보다 늦으면 거절, 공개 전엔 블록이 관객에게 안 보임, 공식 이미지는 바로 보임, 무대를 지우면 그 무대 블록 처리, 25:30 같은 시각

### 3. 프론트

- [x] 주최측 페이지 "타임테이블" 메뉴(T-8): 날짜 알약, 무대 추가, 공개 스위치, 블록 칸(빈 곳 추가·블록 수정), 공식 이미지 올리기. 휴대폰 화면
- [x] 공연 홈 타임테이블 탭(`/shows/{id}/timetable`, T-5·T-7): 날짜 알약, 시간표 | 공식 이미지 토글, 블록 칸, 지금 선·지금 블록·지난 블록, 공식 이미지 크게 보기
- [x] 공연 홈 탭 이동: 공지 ↔ 타임테이블

### 4. 완료 기준

- [x] 주최측이 무대와 블록을 넣고 공개하면, 관객이 공연 홈 타임테이블 탭에서 날짜별 블록으로 본다
- [x] 주최측이 공식 이미지를 올리면 관객이 "공식 이미지"로 보고 크게 확대할 수 있다
- [x] 공연 중에는 지금 하는 블록에 라임 테두리와 지금 선이 보인다
- [x] 자정 넘는 블록이 그 공연일 맨 뒤에 바른 시각으로 보인다
- [x] 로그인하지 않은 관객도 볼 수 있다
