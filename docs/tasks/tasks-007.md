# tasks-007: 혼자 쓰는 기록의 바닥 (관람 기록 + 3탭)

## 목표

다른 사용자가 한 명도 없어도 쓸 수 있게, 공연을 찾아 회차별로 "다녀옴 / 갈 예정"을 남기고, 홈·찾기·나 3탭에서 내 공연과 기록을 볼 수 있게 한다. 동행 관련 기능은 걷어낸다.

## 범위

- 포함: 관람 기록, 공연 검색, 하단바 3탭(홈 / 찾기 / 나), 나 탭 연대기·통계, 동행·피드·신호 제거
- 제외: 아티스트 데이터, 공연 수집 범위 확장(2020년 백필, 전국), 오늘의 컷·당일 브이로그·인스타 공유(tasks-008), 예매 인증, 앱(네이티브)

## 체크리스트

### 0. 결정

- [x] 공연 범위: 지금 그대로(KOPIS 대중음악, 서울·경기, 지난 3개월 ~ 앞으로 6개월). 지난 공연은 지우지 않으니 시간이 지나며 쌓임. 그보다 이전 공연은 기록할 수 없음
- [x] 회차: 공연 기간 안에서 사용자가 고른 날짜. 시간은 기록하지 않음 (KOPIS 공연 시간 안내는 글이라 날짜별로 정확히 나누기 어려움)
- [x] 관람 기록: 사용자 + 공연 + 날짜 하나당 하나. 상태는 갈 예정 / 다녀옴. 공연 날이 되어야 다녀옴으로 바꿀 수 있음
- [x] 아티스트: 이번엔 만들지 않음. KOPIS 출연진은 절반 이상 비어 있고, 밴드·솔로도 멤버 본명이 들어가서(허클베리핀 → 이기용·이소영·성장규, WOODZ → 조승연) 아티스트로 쓸 수 없음. 검색은 아티스트가 대부분 들어 있는 공연 이름으로
- [x] 하단바: 홈 / 찾기 / 나. 지도는 찾기 안에서 목록 ↔ 지도 전환으로 유지
- [x] 동행 정리: 피드, 신호, 다른 사람 프로필, 내 동행 탭 제거. 로그 공개 범위는 없애고 모두 나만 보기
- [x] 로그를 남기면 그 공연의 오늘 날짜(공연 기간 밖이면 시작일) 관람 기록이 다녀옴이 됨

### 1. 데이터

- [x] `attendances`: 사용자, 공연, 날짜, 상태(갈 예정 / 다녀옴), 만든 날. 사용자 + 공연 + 날짜 유일
- [x] 옮기기: `show_plans` → 갈 예정(공연 시작일), 로그가 있는 공연 → 다녀옴(공연 시작일). 옮긴 뒤 `show_plans`, `log_signals`, `show_logs.visibility` 삭제
- [ ] 운영 DB의 테스트 유저(새벽세시)와 그 로그·영상 삭제 (실행 전 확인)

### 2. 백엔드

- [x] 동기화 정리: 관람 기록이 있는 공연은 지우지 않음
- [x] 공연 검색 API: 이름으로 검색, 다가오는 공연 / 지난 공연 구분, 페이지 단위 (지금처럼 전부 내려주지 않음)
- [x] 관람 기록 API: 남기기·바꾸기·지우기, 공연별 내 기록
- [x] 홈 API: 다가오는 내 공연(가까운 순), 기록(로그)이 빈 지난 공연
- [x] 나 API: 연도별 연대기, 통계(올해 관람 수, 전체 관람 수, 가장 많이 간 공연장), 내 로그 목록
- [x] 제거: 피드, 신호, 다른 사람 프로필·로그 API, `ShowPlan`, 공개 범위
- [x] 테스트: 다녀옴 날짜 조건, 공연 기간 밖 날짜 거절, 기존 기록 옮기기, 동기화가 기록 있는 공연을 지우지 않는지, 홈·연대기·통계

### 3. 프론트

- [x] 하단바 3탭으로 교체, 로그·내 동행 탭과 다른 사람 프로필 화면 제거
- [x] 홈: 가장 가까운 공연 큰 티켓(D-day), 그다음 공연 작은 티켓, 기록이 빈 지난 공연
- [x] 찾기: 검색, 다가오는 / 지난 공연 전환, 목록 ↔ 지도
- [x] 공연 상세: 날짜 선택, 갈 예정 / 다녀옴
- [x] 나: 연도별 연대기, 로그 벽, 통계, 설정(닉네임, 로그아웃)
- [x] 로그 남기기 화면에서 공개 범위 선택 제거
- [x] Ticket Stub 디자인(시안 8-1 ~ 8-5) 적용

### 4. 완료 기준

- [ ] 지난 공연을 검색해서 다녀옴을 남기면 나 탭 연대기에 보인다
- [ ] 이틀짜리 공연에서 둘째 날만 골라 기록할 수 있다
- [ ] 갈 예정 공연이 홈에 가까운 순서로 보인다
- [ ] 동기화를 다시 돌려도 기록 있는 공연은 사라지지 않는다
- [ ] 기존 로그와 갈 거예요 표시가 관람 기록으로 옮겨져 있다
