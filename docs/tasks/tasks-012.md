# tasks-012: 건의 + 현장 QR

## 목표

현장에 있는 관객이 불편한 점을 그 공연의 주최측에 바로 말하고, 주최측이 한곳에서 보고 답한다. 주최측은 공연별 현장 QR을 받아 입구·부스·화장실 등에 붙이고, 관객은 QR을 찍으면 로그인 없이 공연 홈이 열리고 자동으로 참여되며 건의를 쓸 수 있다.

## 범위

- 포함: 주최측 페이지의 현장 QR 받기, QR로 들어오기(공연 홈 열기 · 자동 참여 · 홈으로), 현장 QR로 건의 쓰기(로그인 없이, 공연 기간에만), 공연 홈 건의 탭(누구나 보기), 주최측 페이지의 건의 보기·답하기
- 제외: 예매 인증 회원의 건의(예매 인증 작업에서), 건의 알림(주최측·관객 모두), 건의 공감·댓글, 신고·차단, 건의 통계
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "건의 · 현장 QR" 줄 — S-1~S-7

## 체크리스트

### 0. 결정

정한 것(PRD)

- [x] 건의를 쓰는 사람: 예매 인증 회원, 또는 현장 QR을 찍은 관객(로그인 없이, 공연 기간에만). 이번엔 현장 QR만
- [x] 보는 건 누구나: 공연 홈 건의 탭은 로그인 없이 읽음
- [x] 작성 경로 표시: 건의마다 "현장 QR" 또는 "예매 인증". 주최측이 믿을 만한 목소리를 구분할 수 있게
- [x] 현장 QR: 공연별로 발급. 찍으면 그 공연의 공연 홈이 열리고 자동으로 참여됨. 참여 취소는 위쪽 "✓ 참여 중"으로

정한 것(추천대로, 2026-10-21)

- [x] QR 주소: 추천은 공연마다 추측하기 어려운 코드를 붙인 `/q/{코드}`. 주최측이 "QR 다시 만들기"를 누르면 코드가 바뀌고 예전 QR은 안 됨(유출 대비)
- [x] QR을 찍은 관객인지 확인하는 방법: 추천은 `/q/{코드}`를 열면 서버가 "그 공연 현장 확인" 쿠키를 붙여 줌. 공연 마지막 날 끝까지 유효. 쿠키가 있는 기기에서만 건의 쓰기가 열림
- [x] 공연 기간: 추천은 공연 첫날 0시부터 마지막 날 다음 날 정오까지(끝나고 돌아가는 길·다음 날 아침 건의까지). 기간 밖에 QR을 찍으면 공연 홈은 열리고 "건의는 공연 기간에만 쓸 수 있어요"
- [x] QR 받기: 추천은 주최측 페이지 "현장 QR" 메뉴에서 QR 이미지(PNG) 내려받기와 인쇄용 A4 한 장(공연 이름 · "찍으면 공지·타임테이블·건의를 볼 수 있어요" · QR). 붙이는 위치별로 QR을 나누지는 않음
- [x] 건의 쓰는 칸: 추천은 내용만(필수, 500자), 사진 선택 1장(공지 이미지 저장소 재사용). 제목·종류는 안 받음
- [x] 이름: 추천은 이름 없이 "현장 관객". 닉네임은 안 받음
- [x] 도배 막기: 추천은 한 기기에서 한 공연에 1분에 1개, 하루 10개까지. 넘으면 "잠시 뒤에 다시 써 주세요"
- [x] 건의 탭 목록: 추천은 최신순. 건의마다 "현장 QR" 칩 · 시각 · 내용 · 사진 · 주최측 답변(있으면 바로 아래 들여서). 맨 위에 "건의 남기기" 버튼(QR을 안 찍었으면 "현장 QR을 찍으면 쓸 수 있어요")
- [x] 주최측 답변: 추천은 건의마다 답변 하나(고치기 가능). 답하면 관객 화면에 "주최측 답변"으로 보임
- [x] 주최측이 숨기기: 추천은 욕설·광고 같은 건의를 주최측이 "숨기기"로 관객 화면에서 내림(기록은 남김). 쓴 사람이 지우기는 이번엔 안 만듦
- [x] 주최측 건의 화면: 추천은 "답 안 한 것 / 전체" 나눠 보기, 최신순, 건의를 누르면 답변 칸. 휴대폰 화면도(현장에서 바로 답하는 경우). 메뉴의 답 안 한 수 배지는 이번엔 안 만듦
- [x] 새 건의 반영: 추천은 공지와 같게. 화면을 열 때·새로고침할 때·다른 앱에 갔다 돌아올 때 확인
- [x] 공연 홈 탭: 건의 탭을 엶. 공지 ↔ 타임테이블 ↔ 건의 옆으로 밀어서 넘기기도 이어 붙임. 커뮤니티는 계속 "곧 열려요"

### 1. 데이터

- [x] 공연의 현장 QR 코드(다시 만들 수 있게)
- [x] `suggestions`: 공연, 작성 경로(현장 QR / 예매 인증), 쓴 기기(도배 막기용), 내용, 사진(선택), 쓴 시각, 숨긴 시각
- [x] 답변: 건의, 쓴 주최측 계정, 내용, 쓴 시각, 고친 시각

### 2. 백엔드

- [x] 현장 QR: `/q/{코드}` → 공연 확인, 현장 확인 쿠키 붙이고 공연 홈으로 보냄. 주최측 API로 QR 코드 보기·다시 만들기. 자기 공연만(아니면 403)
- [x] 관객 건의 API: `/api/shows/{id}/suggestions` 목록(숨긴 건 제외, 로그인 없이), 쓰기(현장 확인 쿠키 + 공연 기간 + 도배 제한 확인)
- [x] 주최측 건의 API: 목록(답 안 한 것 / 전체), 답변 쓰기·고치기, 숨기기·되돌리기. 자기 공연만
- [x] 테스트: QR 쿠키 있으면 쓰기, 없으면 거절, 다른 공연 쿠키로는 거절, 기간 밖 거절, 다시 만든 뒤 예전 코드 거절, 도배 제한, 내용 길이, 숨긴 건의는 관객에게 안 보임, 답변 보임, 다른 공연 403

### 3. 프론트

- [x] 주최측 페이지 "현장 QR" 메뉴: QR 보기 · PNG 내려받기 · 인쇄용 한 장 · 다시 만들기
- [x] QR로 들어오면: 공연 홈 열기, 자동 참여, "참여했어요 · 홈으로" 알림(누르면 홈)
- [x] 공연 홈 건의 탭(`/shows/{id}/suggestions`): 건의 남기기(쓸 수 있을 때만 열림), 건의 목록, 주최측 답변
- [x] 건의 쓰기: 아래에서 올라오는 시트, 내용 · 사진 1장, 올리면 목록 맨 위에 바로
- [x] 주최측 페이지 "건의" 메뉴: 답 안 한 것 / 전체, 답변 쓰기·고치기, 숨기기. 휴대폰 화면
- [x] 탭 이동·옆으로 밀기에 건의 탭 추가

### 4. 완료 기준

- [x] 주최측이 현장 QR을 내려받아 찍으면, 로그인 없이 공연 홈이 열리고 홈에 그 공연이 참여돼 있다
- [x] QR을 찍은 기기에서 공연 기간에 건의를 쓰면 공연 홈 건의 탭에 "현장 QR"로 보인다
- [x] QR을 안 찍은 기기·공연 기간 밖에서는 건의를 쓸 수 없다
- [x] 주최측이 답하면 관객 화면에 답변이 보이고, 숨기면 사라진다
- [x] 로그인하지 않은 관객도 건의와 답변을 볼 수 있다
