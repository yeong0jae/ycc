# tasks-017: 예매 인증

## 목표

현장에 오지 않아도 그 공연을 예매한 관객이 주최측에 건의를 남긴다. 회원이 예매 내역 캡처를 올리면 개발자가 개발자 페이지에서 확인하고, 승인되면 그 공연에 "예매 인증" 건의를 쓸 수 있다. 주최측은 건의마다 현장 QR인지 예매 인증인지 보고 믿을 만한 목소리를 구분한다.

## 범위

- 포함: 공연 홈 건의 탭에서 예매 인증 신청(캡처 올리기), 인증 상태(확인 중 · 승인 · 다시 올려 주세요), 개발자 페이지 예매 인증 검수(승인 · 거절 사유), 예매 인증 회원의 건의 쓰기, 건의의 "예매 인증" 표시, 프로필의 인증한 공연
- 제외: 예매처 연동 자동 인증, 결과 알림(푸시 · 메일), 주최측이 직접 인증하기, 인증 통계
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc)에 "예매 인증" 줄 — V-1 인증 전, V-2 인증 시트, V-3 확인 중, V-4 다시 올리기, V-5 인증됨, V-6 프로필, V-7 커뮤니티 표시, V-8 개발자 검수
