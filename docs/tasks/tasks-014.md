# tasks-014: 커뮤니티

## 목표

공연마다 관객끼리 이야기하는 곳을 연다. 공연 홈 "커뮤니티" 탭에서 누구나 글을 보고, 로그인한 회원이 자유·질문·추천·후기·동행 글을 쓰고 댓글로 답한다. 공연 전엔 질문, 당일엔 현장 이야기, 끝난 뒤엔 후기가 모이는 곳.

## 범위

- 포함: 공연 홈 커뮤니티 탭(목록 · 글 보기), 글 쓰기·고치기·지우기(로그인), 사진, 댓글, 좋아요, 신고와 개발자 숨기기, 로그인이 필요할 때 시트(M-3)
- 제외: 동행 매칭(글 종류 "동행"으로만), 대댓글, 알림(내 글에 댓글이 달렸을 때 등), 차단, 예매 인증 배지(예매 인증 작업에서), 주최측이 커뮤니티 관리하기, 검색
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "커뮤니티 · 스레드 스타일" 줄 — C-1 목록, C-2 글 보기, C-3 새 글, C-4 로그인 시트

## 체크리스트

### 0. 결정

정한 것(PRD)

- [x] 보는 건 누구나(로그인 없이), 쓰는 건 회원만
- [x] 공연마다 글 목록, 종류가 있음
- [x] 동행: PRD에선 뺐지만 글 종류 "동행"으로 넣음(2026-10-21). 매칭·쪽지는 없음, 댓글로만

정한 것(추천대로, 2026-10-21)

- [x] 글 종류: 자유 · 질문 · 추천 · 후기 · 동행 다섯(2026-10-21, OOTD는 뺌). 글 쓸 때 하나 고름. 목록 위 칩으로 골라 보기(전체 · 자유 · 질문 · 추천 · 후기 · 동행)
- [x] 글 모양: 추천은 제목 없이 내용만(1,000자) + 사진 4장까지(공지 이미지와 같은 방식). SNS처럼 가볍게
- [x] 목록: 추천은 최신순. 글마다 종류 칩 · 닉네임 · 시각 · 내용 3줄 · 사진(첫 장 크게, 여러 장이면 "+2") · 좋아요 수 · 댓글 수. 누르면 글 보기
- [x] 글 보기: 추천은 따로 주소(`/shows/{id}/community/{postId}`) — 링크로 나눌 수 있게. 내용 전부 · 사진 넘겨 보기 · 댓글 목록 · 아래 댓글 입력
- [x] 댓글: 추천은 한 단계만(대댓글 없음), 300자, 사진 없음. 질문 글에 답하는 용도
- [x] 좋아요: 글에만 하트 하나, 회원만(2026-10-21). 다시 누르면 취소. 댓글엔 없음
- [x] 고치기·지우기: 추천은 내 글·내 댓글만. 고치면 "수정됨". 지우면 바로 사라짐(기록은 남김). 댓글이 달린 글을 지우면 댓글도 같이 안 보임
- [x] 쓰는 사람 표시: 추천은 닉네임 + 시각. 닉네임 첫 글자 동그라미. 공연 주최측 계정이 쓴 건 이번엔 없음
- [x] 처음 글 쓸 때 닉네임: 추천은 쓰기 시트 위에 "신나는떼창0428(으)로 올라가요 · 바꾸기". 바꾸기를 누르면 프로필의 닉네임 시트
- [x] 로그인 안 했을 때(2026-10-21): 글쓰기 · 좋아요 · 댓글 · 신고는 회원만. 누르면 그 자리에서 로그인 시트(M-3), 로그인하면 이 화면으로 돌아옴. 시트 제목은 누른 것에 따라
  - 글쓰기: "글을 쓰려면 로그인이 필요해요"
  - 좋아요: "좋아요를 누르려면 로그인이 필요해요"
  - 댓글: "댓글을 남기려면 로그인이 필요해요"
  - 신고: "신고하려면 로그인이 필요해요"
  - 아래 설명은 같게 "로그인해도 이 화면으로 바로 돌아와요"
- [x] 신고: 추천은 글·댓글마다 "신고"(회원만, 사유 고르기: 욕설·비방 / 광고·도배 / 개인정보 / 기타). 개발자 페이지에 신고 목록, 개발자가 숨기기·되돌리기. 같은 글 신고가 3번 쌓이면 개발자가 보기 전에 먼저 숨김
- [x] 도배 막기: 추천은 한 회원이 한 공연에 1분에 글 1개, 댓글은 10초에 1개
- [x] 공연 기간: 추천은 제한 없음(공연 전 질문, 끝난 뒤 후기)
- [x] 새로 반영: 추천은 공지와 같게. 탭을 열 때·새로고침할 때·다른 앱에 갔다 돌아올 때
- [x] 공연 홈 탭: 커뮤니티 탭을 엶. 건의 ↔ 커뮤니티 옆으로 밀어서 넘기기도 이어 붙임
- [x] 프로필 사진(2026-10-22): 프로필 카드 동그라미를 눌러 사진 고르기·지우기. 가운데를 정사각형으로 잘라 512px로 올림. 글·댓글·새 글 시트에 보임. 없으면 닉네임 첫 글자. 탈퇴하면 사진도 지움
- [x] 설정(2026-10-22): 프로필 우측 위 톱니바퀴 → `/me/settings`. 서비스(공연 추가 요청 · 이용약관 · 개인정보 처리방침), 계정(로그아웃 · 회원 탈퇴)을 프로필에서 옮김

- [x] 회원 API: 글 쓰기·고치기·지우기, 사진 올리기, 댓글 쓰기·고치기·지우기, 좋아요·취소, 신고
- [x] 개발자 API: 신고 목록, 숨기기·되돌리기
- [x] 테스트: 비회원 보기 · 쓰기 401, 남의 글 고치기·지우기 403, 지운·숨긴 글은 안 보임, 좋아요 한 번만, 신고 3번이면 숨김, 같은 사람 같은 대상 신고 한 번만, 도배 제한, 길이 제한
