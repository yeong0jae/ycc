# tasks-005: 로그 (공연날 브이로그 피드)

## 목표

공연 날의 짧은 순간들을 찍어 "그날의 브이로그"로 남기고, 이 로그가 쌓여 프로필이 되며, 같은 공연을 다녀온·갈 사람들의 로그를 피드에서 볼 수 있게 한다. 셋로그처럼 편집 없이 있는 그대로 남기는 방식.

## 범위

- 포함: 순간별 2~4초 촬영(웹 카메라·갤러리), 컷 합치기, 그날의 한 곡·한 줄, 공개 범위, 프로필 로그 벽, 로그 피드(다녀온 공연 / 갈 공연), "갈 거예요" 표시, "나도 거기 있었어" · "다음엔 같이" 신호
- 제외: 모두의 로그(같은 순간 단체 영상), 동행과 컷 합치기, 푸시 알림, 예매 인증 배지, 앱(네이티브)

## 체크리스트

### 0. 결정

- [x] 플랫폼: 웹(모바일 브라우저 카메라). 푸시 알림 없이 로그 탭 배너로 안내
- [x] 순간: 굿즈 줄 / 입장 대기 / 공연 직전 / 끝나고. 공연 중 촬영은 받지 않음
- [x] 컷: 2~4초, 공연 하나에 최대 4컷
- [x] 합치기: 백엔드에서 ffmpeg로 하나의 영상으로 합침
- [x] 영상 저장: 서버 디스크(Docker 볼륨). 배포 시 오브젝트 스토리지로 이전
- [x] 공개 범위: 프로필에 남기기(기본) / 나만 보기
- [x] "갈 공연": 콘서트 상세의 "갈 거예요" 버튼으로 표시 (나중에 예매 인증으로 대체)
- [x] "나도 거기 있었어": 같은 공연에 로그를 남긴 사람끼리만 누를 수 있음
- [x] "다음엔 같이": 서로 눌러야 보임. 한쪽만 누른 건 상대에게 보이지 않음
- [x] 용량·보관: 컷당 10MB 이하, 앞 4초만 사용. 합친 영상만 남기고 원본 컷은 합친 뒤 삭제. 소리는 담지 않음

### 1. 데이터

- [x] `show_logs`: 사용자, 공연, 그날의 한 곡, 한 줄, 공개 범위, 합친 영상 경로, 썸네일, 만든 날
- [x] `show_log_clips`: 로그, 순간, 순서, 컷 영상 경로, 길이
- [x] `show_plans`: "갈 거예요" (사용자, 공연)
- [x] `log_signals`: 보낸 사람, 받은 사람, 공연, 종류(나도 거기 있었어 / 다음엔 같이)

### 2. 백엔드

- [x] 컷 업로드: 길이·용량·형식 검사, 공연 하나에 최대 4컷
- [x] 로그 완성: 컷을 ffmpeg로 합치고 썸네일 생성
- [x] 로그 조회: 내 로그, 다른 사람 프로필 로그(공개분만), 공연별 로그
- [x] 피드: 다녀온 공연(내가 로그 남긴 공연의 다른 사람 로그), 갈 공연(내가 "갈 거예요"한 공연에 가는 사람의 지난 로그)
- [x] "갈 거예요" 표시·취소
- [x] 신호 보내기·취소, "다음엔 같이"는 서로 눌렀을 때만 응답에 포함
- [x] 영상 파일 제공 (로그인 사용자만, 공개 범위 확인)
- [x] 테스트: 업로드 검사, 공개 범위, 신호 조건, 피드 구성

### 3. 프론트

- [x] 하단바 4개: 콘서트 / 로그 / 내 동행 / 내 정보
- [x] 로그 피드: 다녀온 공연 / 갈 공연 전환, 공연 날 배너
- [x] 찍기: 순간 선택 → 2~4초 촬영 또는 갤러리 선택 → 컷 진행 표시
- [x] 그날의 브이로그: 미리보기, 그날의 한 곡·한 줄, 공개 범위, 남기기
- [x] 프로필 로그 벽: 내 정보, 다른 사람 프로필
- [x] 콘서트 상세: "갈 거예요" 버튼
- [x] 신호 버튼: 나도 거기 있었어 / 다음엔 같이

### 4. 완료 기준

- [ ] 휴대폰 브라우저에서 순간 2개 이상 찍어 로그를 남기면 하나의 영상으로 합쳐진다
- [ ] 남긴 로그가 내 프로필 로그 벽과 다른 사람의 피드에 보인다
- [ ] "나만 보기" 로그는 다른 사람에게 보이지 않는다
- [ ] 서로 "다음엔 같이"를 눌렀을 때만 서로에게 표시된다
