# tasks-015: 전체 커뮤니티

## 목표

공연마다 흩어진 커뮤니티 글을 한곳에서 본다. 하단 탭 바에 "커뮤니티"를 넣고, 참여한 공연들의 글(또는 모든 공연의 글)을 한 피드로 모아 보여 준다. 글마다 어느 공연 글인지 보이고, 누르면 그 공연 커뮤니티로 간다. 글은 지금처럼 공연에 속하고, 전체 피드는 모아 보기만 한다.

## 범위

- 포함: 하단 탭 바 커뮤니티 탭, 전체 피드(내 공연 / 모든 공연, 종류 칩), 글마다 공연 이름, 전체 피드에서 글쓰기(공연 고르기 → 새 글), 비어 있을 때 화면
- 제외: 공연에 속하지 않는 글, 인기순 정렬, 검색, 팔로우, 알림
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "전체 커뮤니티" 줄 — G-1 피드, G-2 비어 있을 때, G-3 공연 고르기, TB-4 탭 바 4개

## 체크리스트

### 0. 결정

정한 것(시안)

- [x] 탭 바: 홈 · 찾기 · 커뮤니티 · 프로필. 커뮤니티 아이콘은 말풍선. 탭마다 72px(4개면 300px)
- [x] 피드 모양: 공연 홈 커뮤니티(C-1)와 같은 스레드 스타일. 이름 아래 공연 이름 칩("노들 뮤직 페스타 ›", 포스터 없이). 누르면 그 공연 커뮤니티
- [x] 위쪽: 내 공연 / 모든 공연 전환, 종류 칩(전체 · 자유 · 질문 · 추천 · 후기 · 동행), 글쓰기 줄("참여한 공연 이야기를 남겨 보세요")
- [x] 글쓰기: 먼저 "어느 공연에 쓸까요?"(참여한 공연 중), 다음은 새 글 시트(C-3). 그 공연 커뮤니티에도 올라감
- [x] 비어 있을 때(G-2): "참여한 공연의 글이 여기 모여요" + 공연 찾아보기 · 모든 공연 글 보기

정한 것(추천대로, 2026-10-22)

- [x] "내 공연" 기준: 추천은 홈과 같은 참여 목록(로그인했으면 계정, 아니면 이 기기). 로그인 안 해도 내 공연 피드를 볼 수 있음
- [x] 처음 보여 줄 보기: 추천은 참여한 공연이 있으면 "내 공연", 없으면 "모든 공연". 고른 보기는 이 기기에 기억
- [x] 모든 공연: 추천은 띄운(검수된) 공연의 글 전부, 최신순. 끝난 공연 글도 포함
- [x] 공연 고르기 순서: 추천은 진행 중 → 다가오는 → 지난 공연. 참여한 공연이 하나면 고르기를 건너뛰고 바로 새 글. 없으면 "먼저 공연에 참여해 주세요" + 공연 찾아보기
- [x] 글 보기: 추천은 지금 주소(`/shows/{id}/community/{postId}`) 그대로. 뒤로 가면 전체 피드로 돌아옴(스크롤 위치 그대로)
- [x] 공연 홈 커뮤니티 탭에서는 공연 이름 칩을 안 보여 줌(이미 그 공연이라서)
- [x] 로그인: 글쓰기 · 좋아요 · 댓글 · 신고는 지금처럼 회원만, 그 자리에서 로그인 시트
- [x] 더 불러오기: 무한 스크롤(끝에 가까워지면 20개씩 저절로). 공연 홈 커뮤니티 탭도 버튼 대신 같은 방식으로
- [x] 새로 반영: 추천은 탭을 열 때 · 다른 앱에 갔다 돌아올 때

### 1. 데이터

- [x] 새 테이블 없음. 글에 공연 이름을 같이 내려줌

### 2. 백엔드

- [x] 전체 피드 API: `/api/community` — 공연 여러 개(`showIds`) 또는 전부, 종류, 더 불러오기. 띄운 공연만. 글마다 공연 id · 이름
- [x] 공연 홈 목록 응답과 같은 모양(좋아요 · 댓글 수 · 내 글 · 좋아요 했는지)
- [x] 테스트: 내 공연만 · 모든 공연, 숨긴 공연(검수 전·숨김)의 글은 안 보임, 숨김·지운 글 안 보임, 종류 골라 보기, 더 불러오기

### 3. 프론트

- [x] 전체 피드(G-1): 내 공연 / 모든 공연, 종류 칩, 글쓰기 줄, 글 목록(공연 이름 칩), 더 보기
- [x] 비어 있을 때(G-2)
- [x] 공연 고르기 시트(G-3) → 새 글 시트
- [x] 글 항목에 공연 이름 칩(전체 피드에서만)

### 4. 완료 기준

- [x] 하단 탭 바에서 커뮤니티를 누르면 참여한 공연들의 글이 한 피드로 보인다
- [x] "모든 공연"으로 바꾸면 띄운 모든 공연의 글이 보인다
- [x] 글의 공연 이름을 누르면 그 공연 커뮤니티로 간다
- [x] 전체 피드에서 공연을 골라 글을 쓰면 전체 피드와 그 공연 커뮤니티 둘 다에 보인다
- [x] 참여한 공연이 없으면 G-2 화면이 보인다
