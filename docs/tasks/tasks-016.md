# tasks-016: 맵

## 목표

공연 현장에서 무대·화장실·푸드존·게이트가 어디 있는지 공연 홈 "맵" 탭에서 바로 찾는다. 주최측은 인스타에 올리던 공식 맵 이미지 한 장만 올리면, Vertex AI Gemini가 그 그림에서 장소를 읽어 핀 초안을 만들고, 주최측이 확인해서 공개한다. 무대 핀은 타임테이블과 이어져 지금·다음 순서가 보인다.

## 범위

- 포함: 공연 홈 맵 탭(공식 이미지 · 맵), 주최측 공식 맵 이미지 올리기, Gemini 핀 초안, 주최측 핀 확인·고치기·공개, 무대 핀 ↔ 타임테이블 무대 잇기
- 제외: 실제 위치(GPS)·내 위치, 길 찾기, 우리가 직접 그린 지도, 공식 타임테이블 이미지에서 블록 자동 채우기(같은 방식으로 나중에)
- 시안: 공지 시안 캔버스(claude.ai/artifact/ET6aBXRm51BLqZb2kWUoZc) "맵" 줄 — MP-1 공식 이미지, MP-2 맵, MP-3 화장실 골라 보기, MP-4 무대 핀, MP-5 주최측 핀 고치기. 시안의 "우리 맵"은 "맵"으로 부름

### 1. 데이터

- [x] `map_images`: 공연, 순서, 저장 위치, 가로·세로, 올린 시각(공지 이미지 저장소 재사용)
- [x] `map_pins`: 공연, 이미지, 종류, 이름, 설명(선택), 위치(이미지 기준 0~1 비율), 이어진 타임테이블 무대(선택), AI가 만든 핀인지
- [x] 공연의 맵 공개 여부
- [x] 맵 이미지의 보여 줄 범위(원본 기준 0~1 비율)

### 2. 백엔드

- [x] 주최측 API: 공식 맵 이미지 올리기 · 지우기 · 순서, 핀 추가 · 고치기 · 옮기기 · 지우기, 공개 켜고 끄기, AI로 다시 찾기. 자기 공연만
- [x] Gemini 호출: 이미지를 보내 장소 목록(이름 · 종류 · 상자 좌표)을 받아 핀 초안으로 저장. VM 서비스 계정으로 인증(공지 이미지 GCS와 같은 방식)
- [x] 관객 API: `/api/shows/{id}/map` — 공식 이미지, (공개됐으면) 핀, 무대 핀의 지금·다음 순서에 쓸 무대 id
- [x] 인프라: Vertex AI API 켜기, VM 서비스 계정에 Vertex AI 사용 권한(terraform), 운영 compose에 MAP_AI_ENABLED (terraform apply 필요)
- [x] 테스트: 핀 추가·고치기·지우기, 다른 공연 403, 공개 전엔 핀이 관객에게 안 보임, 공식 이미지는 바로 보임, AI 응답을 핀으로 바꾸기(가짜 응답으로), 무대 이름 자동 잇기

### 3. 프론트

- [x] 공연 홈 맵 탭(`/shows/{id}/map`): 전환 없음, 공식 이미지 크게 보기
- [x] 맵: 보여 줄 범위만 자른 공식 이미지 위 핀, 선 아이콘 종류 줄(고른 종류만 핀), 목록, 두 손가락으로 키우기 · 끌어서 둘러보기 · 두 번 눌러 키우기(PC는 휠 · 끌기), 키워도 핀 크기 그대로, "원래대로", 핀 누르면 카드
